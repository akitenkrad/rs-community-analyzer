# 倫理

`community-analyzer` は，組織 / コミュニティのコミュニケーションにおける
**構造的なゆがみ**を検出するために作られている．個人を評価するためのもので
はない．

関連: [アーキテクチャ](architecture.md) / [ユースケース](use-cases.md)．

## 想定される用途

* このライブラリは，組織 / コミュニティのコミュニケーションにおける構造的な
  ゆがみを検出するためのものである．個人の評価，ランク付け，処罰のために
  転用しては**ならない**．
* 仮説は，チャンネル，スレッド，ロールといったレベルでのコミュニケーションの
  健全性のパターンを記述するものであり，特定の個人の価値や成果を表すものでは
  ない．サマリーのしきい値は初期段階のキャリブレーション用ヒューリスティック
  であり，臨床的判断や人事的判断ではない．

## 集計値のみの出力

* レポートは**集計値のみ**を表示する．
* ユーザー単位の唯一の成果物は `tables/h3_pagerank.csv` であり，**デフォルトで
  匿名化される**．

## 匿名化

`Anonymizer`（`Anonymizer::new(true)` で構築する）は，出力を書き出す際に生の
ユーザー ID をソルト付きハッシュに置き換える．ソルトは**実行ごとにランダムで，
永続化されない値**であるため，匿名化された ID を実行間で突き合わせることは
できない．匿名化は呼び出し側が明示的に無効化できるが，デフォルトでは有効で
ある．

## 生 ID 漏洩なしの監査

ランタイム監査テスト `test_finalize_report_assets_no_raw_id_leak` は，匿名化が
明示的に無効化されていない限り，生のプラットフォームのユーザー ID が
`report.md`，`metrics.json`，図表，PageRank CSV のいずれにも現れないことを
強制する．この保証はテストスイートの一部であり，漏洩なしの契約は実行のたびに
チェックされる．
