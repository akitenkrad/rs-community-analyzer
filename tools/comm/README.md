# comm-nlp-sidecar

`comm-analyzer` クレートが起動する Python NLP サイドカー（stance / sentiment /
embedding / clustering）．Rust 側から `tokio::process` で子プロセスとして起動し，
JSONL（1 行 1 メッセージ）を双方向にやり取りする（設計書 §5.6 / §6）．

## セットアップ

リポジトリルートから uv ワークスペースとして同期する（ML 依存は数 GB．通常運用時のみ実行）．

```bash
uv sync --all-packages
```

### モデルの事前 pull

```bash
uv run python tools/comm/scripts/download_models.py --profile balanced
# fast / quality / all も指定可能
```

### オフライン環境（社内 VLAN / エアギャップド）

オンライン環境で 1 回 pull した後は，以下の環境変数でオフライン動作する．

```bash
export TRANSFORMERS_OFFLINE=1
export HF_HUB_OFFLINE=1
```

## `--mock` モード（stdlib のみ）

テスト / CI 用に，**Python 標準ライブラリのみ**で動作する決定的なモックモードを持つ．
ML ライブラリ（torch / transformers / sentence-transformers / hdbscan /
umap-learn / numpy / scipy）は一切 import されない．

```bash
python3 tools/comm/src/nlp_sidecar.py --mock
```

モック値は決定的（同じ入力 → 同じ出力）であり，Rust 側の統合テストはこの契約に依存する．

## JSONL プロトコル

stdin に 1 行 1 リクエスト（JSON オブジェクト）を書き込むと，stdout に 1 行 1
レスポンスが返る．`task` フィールドで種別を判別し，`id` はそのまま echo back される．
EOF で終了コード 0．不正な行は `{"task":"error", ...}` を返してループは継続する．

### リクエスト

| task | フィールド |
|------|------------|
| `stance` | `id:str`, `text:str`, `context:str\|null` |
| `sentiment` | `id:str`, `text:str` |
| `embed` | `id:str`, `texts:[str]` |
| `cluster` | `embeddings:[[float]]`, `min_cluster_size:int` |

### レスポンス

| task | フィールド |
|------|------------|
| `stance` | `id:str`, `label:str` ∈ {support,neutral,disagree,clarify}, `score:float` |
| `sentiment` | `id:str`, `polarity:float` ∈ [-1,1], `magnitude:float` ∈ [0,1] |
| `embed` | `id:str`, `vectors:[[float]]`（入力テキスト 1 件につき 1 ベクトル，L2 正規化） |
| `cluster` | `labels:[int]`（`-1`=ノイズ）, `num_clusters:int` |
| `error` | `id:str`, `message:str` |

### モック値の契約（決定的）

- `stance` → `label="neutral"`, `score=0.5`
- `sentiment` → `h = Σ ord(c)`; `polarity = ((h%201)-100)/100.0`; `magnitude = (h%100)/100.0`
- `embed` → 入力ごとに `sha256(text)[:8]` バイトを float 化し L2 正規化した 8 次元ベクトル
- `cluster` → `k = max(1, n // max(1, min_cluster_size))`; `labels[i] = i % k`
